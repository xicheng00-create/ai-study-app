## 二、页面流程（Page Flow）

```
            ┌──────────┐
            │  登录页   │  (教师·学生 一键演示)
            └────┬─────┘
   role=teacher ──┴── role=student
        │                  │
  ┌─────┴──────┐   ┌──────┴─────────────────────────────┐
  │ 管理后台     │   │ 学生：学习 ↔ 测评 ↔ 进度 ↔ 周报       │
  │ ·资料与章节 │   │ · 学习：人设→意图路由→苏格拉底引导(≤12轮,CHAT-004门控,多对话) │
  │ ·账号管理   │   │ · 测评：老师已发布列表→作答→批改→错题明细(QUIZ-004) │
  │ ·全班概览   │   │ · 进度：四态+趋势(PROG-003)+按章提问(PROG-002)+薄弱点+间隔复习状态机 │
  └─────┬──────┘   │ · 周报：概况+AI建议                   │
        │          └─────────────────────────────────────┘
   ┌────┴──────────────────────────────┐
   │ 教师「测评」：选章→生成草稿→预览确认→发布；重出→新version(superseded) │
   └───────────────────────────────────┘
   右上角头像 → 菜单(改密/退出) → 返回登录页
```

- **数据隔离**：学生进度/测评仅本人；教师概览与周报聚合 3 人；题目内容全班统一（同 quiz_id）。
- **权限边界**：学生无「上传/建章节/出题」入口；教师无独立聊天 UI（学习/测评 tab 在教师端为管理/发布/聚合视角）。

## 三、掌握度与薄弱点（在原型中的体现）

- **单元**=章节；每章掌握度 `M` 由该章关联题作答加权计算（见 Design Spec §3.5 / PRD 功能4）。
- **四态**：已掌握(M≥80 且≥2次) / 进行中(50–79) / 薄弱(<50) / 未评估(从未测验，不计入薄弱)。
- **进度页**：四态计数 + 分布环图 + 成绩趋势折线 + 各章状态（含按章提问数）+ 薄弱点卡（错题依据）。
- 原型内置示例：c1 未评估、c2 已掌握、c3 进行中、c4 薄弱。

## 六、预览方式

1. 浏览器打开 `index.html`。
2. 登录页点「教师视图」或「学生视图」进入。
3. **学生学习**：顶部可见人设/薄弱章标签；意图路由 chips（答疑/复习/出题）；对话走苏格拉底引导（AI 反问，不直接给答案）；点「模拟第12轮」看护栏强制结论；右上「＋新对话」多对话管理；对话区顶部门控条提示 AI 生成需核对。
4. **学生测评**：作答教师发布的同题 → 提交后看**错题明细**（你的答案/正确答案/原因）。
5. **学生进度**：四态环图 + **成绩趋势折线** + 按章提问数 + 薄弱点（依据）+ 一键生成巩固练习（间隔复习状态机：作答后 interval 1→3→7，答错重置 1）。
6. **教师测评**：选章「生成草稿」→ 预览题目「确认发布」；已发布可「重出」生成新 version（旧版 superseded）。
7. **教师管理后台**：资料带解析态（已解析/解析中/解析失败可重试）；删章节走二次确认 + 7 天窗口软删（F7）。
8. **教师周报**：全班聚合概览 + 共性薄弱 + AI 教学建议（RPT-004）。
